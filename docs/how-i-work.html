How I work

From a problem to verified software

First I understand the problem and design the system. Then I work with agents in tiers: one reasons, another decides how it gets built, and others execute. FDS keeps what each agent does in plain view.

  1. ✓1
    Me

    I recognize the problem

    I understand what needs solving, and for whom, before writing a line of code.

  2. ✓2
    Me

    I design the system

    I define the architecture: the pieces, their boundaries and how they connect.

  3. ✓3
    Agent · reasoning

    I consult the agent that reasons best

    It has the strongest reasoning: it checks my design and flags the risks before anything gets built.

  4. ✓4
    Agent · technical decision

    It delegates the technical decision

    Another agent chooses how the system gets built: the approach, the structure and the order.

  5. ✓5
    Agents · execution

    It hands out the tasks

    Faster, more concise agents that are very good at programming take each task and carry it out.

    Task 1 · readyTask 2 · readyTask 3 · ready
  6. ✓6
    Me

    I review and verify

    At the end I review what the agents did. Nothing counts as done without passing through me.
